# HyprQuickPaper GNOME

![HyprQuickPaper GNOME](assets/demo.gif)

A lightweight GNOME/GTK4 wallpaper selector inspired by the visual style and interaction ideas of [ilyamiro's dotfiles](https://github.com/ilyamiro), particularly the Hyprland-oriented workflow and the visual approach used in that environment. This project provides a standalone GNOME implementation without Quickshell or Wofi.

The selector opens as a transparent overlay, displays wallpapers as an animated carousel, keeps the selected wallpaper visually prominent, supports circular keyboard navigation, and applies the selected image through GNOME's background settings.

## Dependencies

The project is intended for Fedora GNOME.

Install the system dependencies:

```bash
sudo dnf install gtk4 python3-gobject python3-cairo jq ImageMagick
```

The runtime also expects GNOME's `gsettings` command and a Wayland session.

The project was inspired by the dotfiles approach in [ilyamiro/ilyamiro](https://github.com/ilyamiro). It is an independent GNOME/GTK4 implementation rather than a direct dependency or port of that repository.

## Installation

Clone the repository and enter it:

```bash
git clone <your-repository-url>
cd hyprquickpaper-gnome
```

Make the installer executable:

```bash
chmod +x install.sh
```

Run it:

```bash
./install.sh
```

The installer asks where your wallpapers are stored and which GNOME keyboard shortcut should open the picker. The default shortcut is `Super+W`. GNOME accelerator syntax can be used, for example `<Super>w` or `<Super><Alt>w`.

The wallpaper directory default is selected automatically in this order:

1. `~/Pictures/Wallpapers` if it already exists.
2. `~/Imagens/Wallpapers` if it already exists.
3. `~/Pictures/Wallpapers` if `~/Pictures` exists.
4. `~/Imagens/Wallpapers` if `~/Imagens` exists.
5. `~/Pictures/Wallpapers` otherwise.

The chosen directory is created automatically when necessary.

The thumbnail cache is stored in:

```text
~/.cache/hyprquickpaper/thumbs
```

After installation, test the selector with the shortcut configured by the installer. You can also run it directly:

```bash
./app.py
```

On Wayland, you can explicitly use:

```bash
GDK_BACKEND=wayland ./app.py
```

## GNOME shortcut

`install.sh` creates a GNOME custom shortcut automatically. It asks for the shortcut during installation and uses `Super+W` when you press Enter without entering another value. Existing GNOME custom shortcuts are preserved.

The generated shortcut runs the project with Wayland explicitly enabled.

To change the shortcut later, use:

**Settings → Keyboard → View and Customize Shortcuts → Custom Shortcuts**

Look for **HyprQuickPaper GNOME** and edit its shortcut.

### Changing shortcuts

Shortcut definitions are near the top of `app.py`, directly below the application paths:

```python
KEY_NEXT = {"j", "right"}
KEY_PREVIOUS = {"k", "left"}
KEY_JUMP_FORWARD = {"d"}
KEY_JUMP_BACKWARD = {"u"}
KEY_APPLY = {"return", "kp_enter", "space"}
KEY_QUIT = {"escape"}
```

Change the values inside these sets to customize the controls.

For example:

```python
KEY_NEXT = {"l", "right"}
```

would make `L` another next-wallpaper shortcut.

The key names are GTK key names. Common examples include `left`, `right`, `up`, `down`, `return`, `space`, and `escape`.


## Customization

The main visual controls are intentionally kept close to the top of `app.py`.

### `config.json`

**Location:** generated by `install.sh` in the project root.

| Attribute | What it controls |
| --- | --- |
| `wallpaper_path` | Directory containing wallpapers. Set by `install.sh`. |
| `cache_path` | Thumbnail cache location. |
| `number_of_pictures` | Number of wallpaper slots visible in the carousel. Prefer an odd number such as `5`, `7`, or `9` so one slot can remain centered. |
| `border_color` | Color of the selected wallpaper border, in formats such as `#1D70F9`. |
| `cache_batch_size` | Number of thumbnails generated concurrently by `cache.sh`. Higher values can make the first cache generation faster but use more CPU and memory. |

Example:

```json
{
    "wallpaper_path": "/home/user/Pictures/Wallpapers",
    "cache_path": "/home/user/.cache/hyprquickpaper/thumbs",
    "number_of_pictures": 7,
    "border_color": "#1D70F9",
    "cache_batch_size": 20
}
```

### Carousel appearance — `app.py`

**Location:** `WallpaperPicker.__init__()`

```python
self.panel_height = 500
self.shear = -0.22
self.spacing = 0.1
```

- `panel_height`: base height of each wallpaper preview.
- `shear`: horizontal perspective/tilt. Values closer to `0` make the tiles straighter.
- `spacing`: horizontal gap between previews. Lower values create a tighter carousel.

The following values control the 3D-like selection effect:

```python
self.max_carousel_scale = 1.18
self.min_carousel_scale = 0.97
self.carousel_power = 1.5
```

- `max_carousel_scale`: maximum size of the selected wallpaper.
- `min_carousel_scale`: scale applied to wallpapers farther from the selection.
- `carousel_power`: how quickly the scale changes as a wallpaper moves away from the center.

A stronger carousel effect can start around:

```python
self.max_carousel_scale = 1.22
self.min_carousel_scale = 0.90
```

### Selected wallpaper horizontal expansion — `app.py`

**Location:** `WallpaperPicker.draw_tile()`

```python
cr.scale(
    scale * 1.2,
    scale
)
```

The first value controls horizontal expansion and the second controls vertical scaling.

For a wider selected wallpaper:

```python
cr.scale(
    scale * 1.3,
    scale
)
```

For no extra horizontal expansion:

```python
cr.scale(
    scale,
    scale
)
```

### Animation speed — `app.py`

**Selection animation:** `animate_selection()`

```python
self.visual_selection += delta * 0.22
```

**Horizontal movement:** `animate_scroll()`

```python
self.content_x += delta * 0.28
```

Higher values make the animation react faster. Lower values produce a slower, softer transition.

The timers that call these animations are also near the corresponding selection and scroll methods:

```python
GLib.timeout_add(16, ...)
```

A smaller interval can increase update frequency, but the compositor and display refresh rate still determine the actual presentation smoothness.

### Window height — `app.py`

**Location:** `show()`

```python
window_height = math.ceil(
    self.panel_height
    * self.max_carousel_scale
)
```

This gives the selected wallpaper enough vertical room to grow without being clipped.

## Uninstallation

To remove the installed application, its cache, and the local configuration, run:

```bash
rm -rf ~/.local/share/hyprquickpaper-gnome
rm -rf ~/.cache/hyprquickpaper
```

The GNOME keyboard shortcut created during installation is stored separately in GSettings. To remove it, open:

**Settings → Keyboard → View and Customize Shortcuts → Custom Shortcuts**

and remove the HyprQuickPaper GNOME shortcut.
